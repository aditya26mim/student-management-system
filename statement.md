
# Project Statement

## Problem Statement
Maintaining student records manually can make searching, updating marks, and calculating results time-consuming and error-prone. A simple computerized system is needed to store student information and perform common academic record operations efficiently.

## Scope
the pproject covers data management of student, students name, marks, student registration, searching, updating marks, calculating total and percentage, displaying results, and deleting student records. Data is stored locally in JSON format.

## Target Users
- Students
- Faculty members
- Academic staff
- parenst
## High-Level Features
- Add student
- Search student by ID, name, or course
- Update subject marks
- Calculate total marks
- Calculate percentage
- Generate Pass/Fail result
- Display all records
- Delete student
- Validate input
- Store data persistently in JSON
